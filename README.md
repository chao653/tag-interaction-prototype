# Tag 交互优化 · 三方案可点击原型（APAC-4695）

针对 Assessment「Question Settings → Standards」标准选择交互的三个改版方案，可点击交互演示：

- **方案 A · 滚动折叠吸顶**：向下滚动列表时，Question 卡 / 说明 / 筛选下拉折叠为「Q1 摘要条 + 搜索框」吸顶，Filters 以浮层展开、不推列表；滚回顶部恢复。
- **方案 B · 全屏弹窗浏览器**：面板内只保留已选结果与入口，点击 Browse Standards 打开大弹窗（左筛选栏 + 双列卡片网格），Done 后回填面板。
- **方案 C · 抽屉加宽分栏**：点击面板右上角展开按钮，抽屉加宽为「左列表 + 右详情（完整描述 + Skills 勾选）」，收起后状态同步。

顶部 Tab 切换三个方案。数据为示意内容，非真实标准库。

设计稿与交互流程见团队 Figma（Assessment 2.5 - General Passage → Question Setting 页 → Tag Interaction Variants section）。

> 本原型为单文件静态页面（`index.html`），无构建依赖，GitHub Pages 直接托管。
